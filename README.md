# IRONBOUND — Conventional Infantry

Six original IRONBOUND house profiles for standard Inner Sphere infantry. No Battle Armor, motorized infantry or mechanized infantry.

These are not DFA Card Builder exports and EV is not official BV2. The approved EV starting values are 300 / 350 / 400 / 450 / 400 / 600. Combat balance remains to be playtested.

SVGs are printable unit records (277 × 183 mm). The insertion Markdown contains the catalogue, chapter introduction, all six Raw image URLs, and the complete supply/replacement/skill procedures.

## Basis

- User-approved original profile specification in the IRONBOUND project.
- IRONBOUND (12): Conventional Infantry; Company Infantry; Encounter Value; measurements in inches.
- Override Core Rules Reference v5.3r1, pp. 15–16: ordered troop rows, first-active-row firepower, one attack, separate damage groups, AI and Anti-Mech procedures.

All six profiles use four squads of seven, Gunnery 4, Ground 1 inch / Sprint 2 inches, Ground TMM 0 / Sprint TMM 1. Jump profiles use Jump 3 inches / Jump TMM 1. Only SRM Jump has Anti-Mech 5. AI is exclusive to the Machine Gun profile. No individual ammunition tracking.

Campaign procedures: recruit 25,000 C-bills; upkeep 1,000 per day including personnel; resupply 1,000 and one day after deployment; replace 1,000 per trooper and one day per batch at an eligible market. A neutralized unit requires new recruitment. Supplies and replacements can be serviced concurrently. Full deployment EV and transport mass remain unchanged after casualties.

The supply and replacement rates are original campaign abstractions chosen to complete the approved profile package; they are not published BattleTech prices. See the insertion Markdown for complete rules.
